# Support

This repository provides reusable guidance, patterns, templates, and notebook/tooling examples for Microsoft Fabric architecture. It is not an official support channel and does not provide an SLA.

## Where to get help

Use the channel that matches your need:

| Need | Recommended channel |
|------|---------------------|
| Product documentation | [Microsoft Fabric documentation](https://learn.microsoft.com/en-us/fabric/) |
| Community questions | [Microsoft Fabric Community](https://community.fabric.microsoft.com/) |
| Product support issue | Your normal Microsoft support path |
| Repository content bug or improvement | Open a GitHub issue or pull request |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md) |

## Before opening an issue

Please check:

- The relevant Microsoft Learn documentation for current product behavior.
- Existing issues and pull requests.
- Whether the question is about this repository's guidance versus a tenant-specific support problem.

Do not include confidential customer, tenant, account, environment, or Microsoft-internal information in public issues.
