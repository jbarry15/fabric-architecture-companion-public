## What it covers

This blog explains how Microsoft Fabric Capacity reservations work, why customers use them for predictable Fabric usage, and how to purchase them through the Azure portal.

Key topics include:

- Reservation commitments and payment options.
- How reservation discounts apply to matching Azure usage.
- Scope choices: resource group, subscription, shared, and management group.
- Fabric Capacity reservation sizing by capacity units (CUs).
- Azure portal purchase flow for Microsoft Fabric reservations.
- Cancel, exchange, refund, and auto-renewal considerations.

## Watch-outs

- Reservation savings depend on steady usage that matches the reservation region, scope, and CU quantity.
- Reservations cover Fabric capacity usage only; storage and networking charges are separate.
- Unused reserved CUs don't carry forward.
- Purchase, refund, exchange, and auto-renewal rules can change, so validate against Microsoft Learn and Azure portal pricing before customer guidance.
